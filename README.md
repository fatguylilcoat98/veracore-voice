## What This Is

`veracore-voice` adds a full voice interface to any Veracore deployment.

It listens for audience questions, silently evaluates whether it can answer,
asks the presenter for permission, and delivers a verified spoken response —
or gracefully hands the question back to the presenter.

The key moment:

> **"Chris, may I answer that?"**

This is human + AI working together in real time.
